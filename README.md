# ManaCode Talents 1.2.0 — WoW 3.3.5a

[Скачать / Download](https://github.com/dmitriinosach/-MANACODE-Talents/releases/latest) · [ManacodeUpdate — установка и обновление / installer and updater](https://github.com/dmitriinosach/-MANACODE-Update/releases/latest)

## Русский

Ветки талантов для WoW 3.3.5a, которые дополняют стандартный интерфейс, а не заменяют его: родное окно талантов растягивается на остальные ветки и символы, а большое окно собирает наборы, билдер десяти классов, цель, библиотеку веток, сравнение и символы.

Закройте игру и распакуйте папку `ManaCode_Talents` в `Interface\AddOns`. Файл `ManaCode_Talents.toc` должен лежать прямо в этой папке. Включите аддон на экране выбора персонажа. Если аддон уже стоял, после обновления перезапустите игру целиком: новые картинки `/reload` не подхватит.

Открыть: **N** или **`/mct`**. Также работают `/mctalents`, `/htpt`, `/htptalents`. `/mct quick` — панель замены символов, `/mct theme` — темы, `/mct lang` — язык, `/mct help` — все команды.

N открывает родное окно талантов Blizzard; уголок справа внизу тянет его к остальным веткам и символам, правила и поведение окна остаются родными. Значок «Ветки талантов» на родном окне открывает большое окно: два набора, билдер, цель, библиотека веток, сравнение A и B, вид «Символы». Меню «⋯» возвращает к родному окну, открывает таланты питомца, темы и настройки.

Билдер не меняет персонажа. «Изучить ветку» раскладывает свободные очки через предпросмотр и подтверждение; уже изученные таланты сбрасываются только у тренера. Для игроков WoWCircle есть третий набор талантов: выключен по умолчанию, включается в настройках, раздел «Сервер», нужен купленный второй набор.

Сохранённые данные (`HTP_TalentsDB`) при обновлении не удаляйте — свои ветки и настройки остаются. Другие аддоны не нужны; цены символов берутся из Auctionator или ManaCode AuctionScan, если они стоят. Поддерживается клиент 3.3.5a (Interface 30300).

## English

Talent builds for WoW 3.3.5a that add to the default interface instead of replacing it: the default talent window stretches to show the other trees and glyphs, and a large window brings together both talent sets, a builder for all ten classes, Target, the build library, comparison and glyphs.

Close the game and extract `ManaCode_Talents` into `Interface\AddOns`; `ManaCode_Talents.toc` must be directly inside that folder. Enable the addon at character selection. If you had the addon before, restart the game after updating: new images do not load on `/reload`.

Open with **N** or **`/mct`** (`/mctalents`, `/htpt`, `/htptalents` also work). `/mct quick` toggles the glyph swap panel, `/mct theme` lists themes, `/mct lang` sets the language, `/mct help` lists commands.

N opens the default Blizzard talent window; drag its bottom-right corner to add the other trees and glyphs, while the window keeps Blizzard's rules and behaviour. The Talent builds icon on it opens the large window: both talent sets, the builder, Target, the build library, A/B comparison and the Glyphs view. The ⋯ menu returns to the default window and opens pet talents, themes and settings.

The builder does not change your character. Learn build spends unspent points through preview and confirmation; learned talents still need a trainer reset. For WoWCircle players there is a third talent set: off by default, enabled in Settings, Server section, and it needs a purchased second set.

Keep your SavedVariables when updating. No other addon is required; glyph prices come from Auctionator or ManaCode AuctionScan if installed. For the original 3.3.5a client, Interface 30300.

## Español

Builds de talentos para WoW 3.3.5a que complementan la interfaz original en lugar de sustituirla: la ventana de talentos de Blizzard se amplía con las otras ramas y los glifos, y una ventana grande reúne las dos especializaciones, el planificador de las diez clases, el objetivo, la biblioteca, la comparación y los glifos.

Cierra el juego y extrae `ManaCode_Talents` en `Interface\AddOns`; `ManaCode_Talents.toc` debe quedar directamente en esa carpeta. Activa el addon en la selección de personajes. Si ya tenías el addon, reinicia el juego tras actualizar: las imágenes nuevas no se cargan con `/reload`.

Abre con **N** o **`/mct`** (también `/mctalents`, `/htpt`, `/htptalents`). `/mct quick` muestra el panel de cambio de glifos, `/mct theme` los temas, `/mct lang` el idioma y `/mct help` todos los comandos.

N abre la ventana de talentos original; arrastra su esquina inferior derecha para añadir los otros árboles y los glifos, sin que cambien sus reglas ni su comportamiento. Su icono Talentos abre la ventana grande: las dos especializaciones, el planificador, el objetivo, la biblioteca, la comparación A y B y la vista de glifos. El menú ⋯ vuelve a la ventana original y abre los talentos de mascota, los temas y los ajustes.

El planificador no cambia tu personaje. Aprender build usa los puntos libres con vista previa y confirmación; los talentos ya aprendidos se restablecen con el instructor. Para los jugadores de WoWCircle hay una tercera especialización: desactivada por defecto, se activa en Ajustes, apartado Servidor, y requiere la doble especialización.

Conserva tus SavedVariables al actualizar. No requiere otros addons; los precios de glifos se leen de Auctionator o ManaCode AuctionScan si están instalados. Para el cliente original 3.3.5a, Interface 30300.
